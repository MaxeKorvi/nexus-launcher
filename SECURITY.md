# Security

В Nexus Launcher 1.1.8 пароли Microsoft не запрашиваются и не сохраняются. Microsoft-вход выполняется через официальный device-code flow.

Для Ely.by пароль используется только во время входа для получения токена Ely.by. После этого пароль не записывается в настройки или на диск. Сохраняется только токен, и в интерфейсе показывается статус: **Шифрование включено**.

TLauncher/TLSkinCape профиль не собирает пароль. Он используется как offline-профиль со скин-совместимостью там, где это поддерживает сервер или установленная модовая система.

Логи запуска маскируют access token. Не отправляйте полный `launcher.log` публично, если внутри есть пути к вашим локальным папкам.


## Статистика

Nexus Launcher в этой сборке не отправляет анонимную статистику. Включить её из интерфейса или через старые настройки нельзя: backend принудительно хранит значение `false`, пока не будет подключён явный сервер сбора и отдельное описание состава данных.


## Загрузчики модов

В 1.1.11 исправлена установка legacy Forge без запуска GUI-установщика и без сохранения лишних данных. Ошибки Java/installer теперь логируются только как техническая диагностика загрузчика; токены аккаунтов в эти сообщения не подставляются.
