# Nexus Launcher — Release 2026.1.1

## Изменения в Release 2026.1.1

- **Безопасность**:
  - Все внешние HTML-данные и новости экранируются с помощью `escapeHtml()`.
  - Удалён небезопасный универсальный `window.api.invoke` из preload, заменён на строгий whitelisted диспетчер с перечнем разрешённых IPC-каналов.
  - Ограничен доступ к файловой системе в `shell:open-path` и `shell:show-in-folder` только пределами домашнего каталога пользователя и appData.
- **Интерфейс и навигация**:
  - Навигация перенесена на левую панель с группами «Главная», «Библиотека» и «Настройки».
  - Добавлена вкладка «Библиотека» для управления сборками, модами, картами, шейдерами и ресурспаками.
  - Профиль игрока и downloads вынесены на правую панель.
  - Улучшена адаптивность: скрытие правой панели и компактный вид левой на малых экранах.
  - Поиск и подробные подсказки о перезапусках добавлены на страницу настроек.

## Исправления 1.1.11

- Исправлена установка старого Forge, включая Minecraft 1.7.10: лаунчер больше не запускает legacy installer с неподдерживаемым `--installClient`, а устанавливает профиль напрямую из `installer.jar`.
- Исправлена ошибка 404 для старых Forge-библиотек: Maven-координаты с classifier вроде `:universal` теперь превращаются в правильный файл `*-universal.jar`.
- Перед скачиванием legacy Forge лаунчер извлекает встроенные Maven-артефакты из `installer.jar`, поэтому не пытается заново скачать то, что уже лежит внутри установщика.
- Downloader теперь поддерживает fallback-URL/mirrors для loader-библиотек и installer-файлов. Если старый URL Forge недоступен, пробуется корректный Maven-адрес.
- Для Forge/NeoForge installer добавлены несколько не-GUI вариантов аргументов и таймаут 120 секунд, чтобы установщик не подвешивал лаунчер.
- Ошибки загрузчиков теперь преобразуются в понятные сообщения вместо сырого Axios/Java traceback.

## Исправления 1.1.9

- Главная страница теперь получает новости с официальной страницы `https://www.minecraft.net/en-us/article`.
- Для каждой новости лаунчер пытается подтянуть реальное изображение через `og:image` / `twitter:image` со страницы статьи.
- Новости про обновления Minecraft, снапшоты, changelog, hotfix, game drop и релизы поднимаются выше обычных промо-новостей.
- Добавлен кэш новостей на 3 часа, чтобы лаунчер быстрее открывался и не зависал из-за сайта.
- Если minecraft.net временно недоступен, показывается последний сохранённый кэш, а не фейковые новости.
- Убран старый mock-список с выдуманными датами.

## Исправления 1.1.8

- Исправлено зависание при установке версий/сборок: очередь больше не запускает сотни ресурсов одновременно.
- Прогресс загрузок теперь обновляется с троттлингом, без IPC-спама и перегруза renderer process.
- Исправлено разворачивание окна на Wayland/frameless Electron: добавлен fallback на размер рабочей области, F11 включает полноэкранный режим.
- Forge installer теперь читает stdout/stderr, не блокируется на выводе и показывает нормальную ошибку.
- Для старого Forge, включая Minecraft 1.12.2, добавлен fallback: если официальный installer падает, профиль Forge извлекается из installer.jar напрямую.
- Для старого Forge предпочтительно используется Java 8, если она найдена.
- Если renderer всё же упал, окно автоматически перезагружается, а не остаётся мёртвым.

## Что изменено

- Полностью закреплён single-window layout: главная, версии, аккаунты, сборки, моды и настройки меняют центральный контент, не ломая правую панель и нижнюю панель запуска.
- Карточки сборок на главной показываются нормальной высотой и не режутся пополам.
- На Windows данные лаунчера по умолчанию хранятся в `%SystemDrive%\NexusLauncher`, а версии — в `%SystemDrive%\NexusLauncher\nexus-versions\<профиль>\`.
- На Linux/macOS установленные версии создаются в `~/.minecraft/nexus-versions/<профиль>/`.
- Кнопка **Папка** рядом с **Играть** открывает:
  - папку выбранной версии/сборки;
  - либо общую папку `nexus-versions`, если версия не выбрана.
- Менеджер версий поддерживает **Vanilla, Fabric, Forge, Quilt, NeoForge**.
- Для Fabric/Forge/Quilt/NeoForge добавлена проверка доступности по конкретной версии Minecraft. Если загрузчика для версии нет, кнопка установки становится недоступной.
- Установленные сборки отображаются в списке установленных версий и могут быть выбраны для запуска.
- Отдельный центр загрузок показывает активные загрузки, очередь, завершённые файлы, прогресс и попытки повтора.
- Скачивание использует `.part` файлы, SHA-1 проверку, повтор попыток при `ECONNRESET`, `socket hang up`, таймаутах и временных сетевых ошибках.
- Для Modrinth `.mrpack` файлы скачиваются через общий менеджер загрузок.
- Ely.by вход работает через Yggdrasil-compatible authserver. Пароль используется только для получения токена и не сохраняется.
- TLauncher/TLSkinCape добавлен как offline-профиль без сбора пароля.
- Для Ely.by при запуске автоматически подключается authlib-injector.
- Для модовых профилей лаунчер пытается поставить TLSkinCape-совместимый skin support через CustomSkinLoader, если для версии и загрузчика найден совместимый файл.
- В интерфейсе отображается только **Шифрование включено**, без технических деталей хранилища.

## Запуск из исходников

```bash
npm install
npm start
```

Или через готовый скрипт:

```bash
./start.sh
```

## Важно про аккаунты

- Microsoft вход работает через официальный device-code flow.
- Ely.by вход реализован через `https://authserver.ely.by/auth`.
- TLauncher/TLSkinCape профиль не запрашивает пароль и не подменяет Microsoft-лицензию. Это offline-профиль со скин-совместимостью для серверов/сборок, которые это поддерживают.


### Приватность и анонимная статистика

В этой сборке отправка анонимной статистики отключена и ничего не отправляет наружу: сервер телеметрии не подключён. Переключатель в настройках оставлен только как будущая опция и визуально отключён, чтобы не вводить пользователя в заблуждение.
